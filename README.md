# ConcordBI

AI-powered semantic-drift investigation for enterprise BI.

## Status

Early development.

## Goal

Detect changes and inconsistencies in business metric definitions,
verify their numerical impact using deterministic execution,
and generate evidence-backed audit findings.

## Stack

- Python
- FastAPI
- Pydantic
- LangGraph
- NVIDIA Nemotron
- Nebius Token Factory
- SQLite
- Dockergit init
